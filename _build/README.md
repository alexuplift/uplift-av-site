# Uplift AV site build

Static site generated by Python. Sources live here; built HTML is committed at the repo root and deployed by Cloudflare on every push to `main`.

| File | Purpose |
| --- | --- |
| gen.py | Main generator: layout, home, services, packages, FAQ, contact, area, audience, about, legal pages |
| site.css | All styles (inlined into every page) |
| services_data.py / audiences.py / cities.py / city_plan.py / legal.py | Page content |
| posts_src.py | Blog posts (markdown). Posts publish automatically when their `date` is today or earlier |
| posts_build.py | Builds /blog, posts, RSS, sitemap entries, and "Planning guides" sections on money pages |
| seo_post.py | Titles, descriptions, clean URLs, preloads, schema extras, 404 page |
| indexnow.py | Pings IndexNow with all sitemap URLs (or URLs passed as args) |
| audit12.py | SEO audit (canonicals, orphans, headings, duplicates, links, titles, descriptions, images, sitemap) |
| build.sh | One-command rebuild into the repo root |

## Publish a scheduled blog post
1. `bash _build/build.sh`
2. `git add -A && git commit -m "Publish post" && git push`
3. Wait for the Cloudflare build to finish, then `python3 _build/indexnow.py`

## Add a new post
Add a dict to `POSTS` in `posts_src.py` (slug `blog/<name>`, date, title ≤60 chars, description 120–160 chars, h1 as the question, answer, body with `## Question?` sections, money page, related posts, image), then rebuild.

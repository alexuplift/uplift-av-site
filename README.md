# Uplift AV website

Static site for upliftavtech.com, deployed by Cloudflare Pages from the `main` branch (no build step, output directory `/`).

- Pages: index, services, packages, faq, contact
- Images: `images/` (keep file names when swapping photos)
- Contact form embed: replace the contents of `<div id="quote-form">` in `contact.html`
